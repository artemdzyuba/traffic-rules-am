# Закон РА «Об обеспечении безопасности дорожного движения» — все 72 вопроса базы с ответами

Тема 2 базы экзаменационных вопросов (pdd-armenia.vercel.app, февраль 2026).
Это вопросы по самому закону: термины-определения, категории прав и возраст, обязанности водителя. Правильный вариант выделен жирным, после «→» — почему. Часть вопросов идёт с картинками (помечены «(рис.)») — там даю ответ и принцип.

## Ядро: цифры и факты, которые надо знать

1. **Возраст для прав:** A, B, C — с **18 лет**; BE — с **19**; D и D1 — с **21 года** (призванным в армию D1 — с 19). Международные: A/B — 18, C — 21, D — 21.
2. **Для категории D** мало возраста: нужно уже иметь права B, C или C1.
3. **Срок прав:** национальные — **10 лет**, международные — **3 года**.
4. **Прицеп до 750 кг** можно таскать с правами B, C, D без категории E.
5. **Регистрация купленного ТС** в дорожной полиции — в течение **15 дней**.
6. **Право управления возникает** с момента **получения удостоверения**, а не сдачи экзамена.
7. **Остановка** — преднамеренно и до 5 минут (или сколько нужно для посадки/погрузки); **стоянка** — преднамеренно и больше 5 минут. Всё непреднамеренное (светофор, затор, поломка, препятствие) закон РА называет **вынужденной остановкой**.
8. **Недостаточная видимость** — меньше **300 м** (туман, дождь, снегопад). **Тёмное время** — от конца вечерних до начала утренних сумерек (не «по часам»).
9. **Мопед** — до 50 см³ и до 50 км/ч. **Автобус** — больше 8 сидячих мест (9+), **легковой** — не больше 8.
10. **С собой обязательны** только права и регистрационные документы ТС; доверенность не нужна.
11. **Приравнены к пешеходам:** инвалидные коляски (и без двигателя, и с двигателем на скорости пешехода), везущие тележку/санки/коляску, **ведущие** велосипед, мопед или мотоцикл. **Приравнен к водителю:** погонщик скота на дороге, обучающий вождению.
12. **Выезд с прилегающей территории — не перекрёсток.** Грунтовая дорога при выезде на асфальт — второстепенная.

## Термины: люди

- Пассажир: только тот, кто в салоне / **в салоне + кто садится или выходит** → **Ответ 2**: пассажиром ты становишься уже в момент посадки-высадки.
- Пешеход: **лицо вне ТС на дороге, кроме дорожных рабочих** / включая рабочих → **Ответ 1**: у дорожных рабочих свой статус.
- К пешеходам приравниваются: коляска без двигателя / тележка-санки-коляска / **все перечисленные** → **Ответ 3**.
- К пешеходам приравниваются: коляска с двигателем на скорости пешехода / ведущие велосипед, мопед, мотоцикл / **все перечисленные** → **Ответ 3**: ключевое — **ведущие**, а не едущие.
- К водителю приравнивается: **погонщик скота по дороге** / погонщик вообще → **Ответ 1**: закон действует только на дороге.
- Обучающий вождению: **приравнивается к водителю** / нет → **Ответ 1**: поэтому отвечает он.
- Обучающийся должен пристёгиваться? → **Ответ 1: должен**, исключений для учебной езды нет.
- Регулировщик: **только уполномоченное лицо** / любой участник движения / все → **Ответ 1**: без полномочий махать руками нельзя.

## Термины: транспортные средства

- Мопед: **до 50 см³ и до 50 км/ч** / 60/60 / 70/70 → **Ответ 1**: запомни «50/50».
- Автобус: **более 8 мест** для сидения / 8 и более → **Ответ 1**: 9 сидячих мест и больше.
- Легковой: **не более 8 мест** / не более 4 → **Ответ 1**: зеркально автобусу.
- Грузовой: **предназначен для перевозки грузов** / только тяжелее 3,5 т → **Ответ 1**: масса тут ни при чём.
- Велосипед: включая инвалидную коляску / **за исключением инвалидной коляски** → **Ответ 2**: коляска — «пешеход».
- Прицеп: любое буксируемое на жёсткой сцепке / **ТС без двигателя, движущееся в составе как единое целое** → **Ответ 2**.
- ТС общего пользования: **трамвай/троллейбус/автобус с остановками по маршруту** / то же + такси → **Ответ 1**: такси — НЕ общего пользования (дважды в базе, второй раз — тоже вариант без такси, **Ответ 2**).
- Разрешённая максимальная масса: снаряжённая масса / **масса с водителем, пассажирами и грузом, установленная изготовителем** → **Ответ 2** (в базе дважды, оба раза — вариант «с водителем, пассажирами и грузом от изготовителя»).

## Термины: дорога и её элементы

- Проезжая часть: для движения ТС / **для движения безрельсовых ТС** → **Ответ 2**: трамвай ездит не по проезжей части.
- Полоса движения: только обозначенная разметкой / **обозначенная или не обозначенная** → **Ответ 2**: полоса есть и там, где разметку стёрли.
- Разделительная полоса: только конструктивная / **конструктивно и (или) разметкой** → **Ответ 2**.
- Тротуар: примыкающий к проезжей части / отделённый от неё / **оба случая** → **Ответ 3**.
- Тротуар и обочины — часть дороги? → **Ответ 1: да**, дорога = проезжая часть + тротуары + обочины + разделительные полосы.
- Выезд с прилегающей территории — перекрёсток? → **Ответ 1: не считается** (поэтому там нет правил перекрёстка, но выезжающий уступает всем).
- Грунтовая дорога выезжает на асфальтобетонную: → **Ответ 1: асфальтированная — главная**.
- Пункт остановки ТС общего пользования: **место посадки-высадки, оборудованное знаками** / просто место → **Ответ 1**.
- Препятствие — что НЕ является: повреждение покрытия / посторонний предмет / неисправный автомобиль / **автомобиль в пробке** → **Ответ 4**: затор — не препятствие, объезжать его по встречке нельзя.

## Термины: режимы движения

- На дорогах РА установлено: **правостороннее** / левостороннее движение → **Ответ 1**.
- Остановка: **преднамеренно, до 5 минут или для посадки/погрузки** / больше 5 минут → **Ответ 1** (в базе дважды; во втором варианте тот же смысл — **Ответ 3**).
- Стоянка: просто больше 5 минут / **больше 5 минут, кроме предотвращения столкновения и прочих законных случаев** → **Ответ 2**: полное определение с оговорками.
- Вынужденная остановка: светофор / пробка / неисправность-опасность-препятствие / **все перечисленные случаи** → **Ответ 4**: в законе РА вынужденная остановка — любая непреднамеренная, включая светофор и затор.
- Недостаточная видимость: тёмное время / нет освещения / **видимость до 300 м при тумане, дожде, снегопаде и т.п.** → **Ответ 3**.
- Тёмное время суток: по часам / **между концом вечерних и началом утренних сумерек** / нет солнца → **Ответ 2**.
- Аварийная ситуация: действия участника движения / **участника движения и (или) регулировщика** → **Ответ 2**: регулировщик тоже может создать угрозу.
- Уступить дорогу: не вынуждать менять направление или скорость / **не вынуждать ВНЕЗАПНО менять направление или скорость** / остановиться безоговорочно → **Ответ 2**: ключевое слово — «внезапно».

## Термины: манёвры

- Перестроение: выезд из полосы / выезд из ряда внутри полосы / **оба случая** → **Ответ 3**.
- Поворот: выезд на другую дорогу / **на другую дорогу или прилегающую территорию** → **Ответ 2**: заезд во двор — тоже поворот.
- Разворот: движение по встречному направлению / **манёвр для изменения направления на противоположное** → **Ответ 2**.
- Объезд: **опережение движущихся ТС без выезда из занимаемой полосы** / с выездом → **Ответ 1**: с выездом из полосы это уже обгон.
- Начало движения: **с места стоянки/остановки, с перестроением или без** / только с перестроением → **Ответ 1**.
- Манёвр: **начало движения (с выездом на соседнюю полосу), перестроение, изменение направления, остановка (с перестроением), разворот** → **Ответ 1**: вариант с уточнениями в скобках.

## Категории, возраст, удостоверения

- Категория A: → **Ответ 3: с 18 лет**.
- Категории B и C: → **Ответ 3: с 18 лет**.
- Категория BE: → **Ответ 3: с 19 лет** (год стажа поверх B).
- Категория D и D1: → **Ответ 4: с 21 года**.
- D/D1 призванным в армию: → **Ответ 2: с 19 лет** (льгота для военных).
- Для D/D1 нужно: **права B, C или C1 и 21 год** → **Ответ 1**: на автобус — только с опытом.
- Прицеп с правами B, C, D без E: → **Ответ 1: до 750 кг**.
- То же с подкатегориями C1, D1: → **Ответ 3: до 750 кг** (цифра та же, другой порядок вариантов!).
- Международные A и B: → **Ответ 3: с 18 лет**.
- Международное C: → **Ответ 3: с 21 года**.
- Международное D, DE, D1, D1E: → **Ответ 3: с 21 года**.
- Национальные удостоверения выдаются: → **Ответ 2: на 10 лет**.
- Международные удостоверения: → **Ответ 2: на 3 года**.
- Право управления возникает: со сдачи экзамена / **с момента получения удостоверения** → **Ответ 2**: без корочки за руль нельзя, даже сдав всё.

## Обязанности водителя

- Регистрация приобретённого ТС в дорожной полиции: → **Ответ 1: в течение 15 дней**.
- За техническое состояние ТС отвечает: **собственник или пользователь** / продавец / станция техосмотра / все → **Ответ 1**.
- До начала движения проверить: тормоза и руль / протектор шин / **всё перечисленное** → **Ответ 3**.
- Предоставлять своё ТС: полиции для доставки нуждающихся в срочной помощи / медработникам по пути (с согласия) / **в обоих случаях** → **Ответ 3**.
- При причастности к ДТП: остановиться / включить аварийку / не перемещать предметы / **выполнить всё перечисленное** → **Ответ 4**.
- Иметь при себе: **права своей категории + регистрационные документы ТС** / ещё и доверенность / всё → **Ответ 1**: доверенность в РА не нужна.
- Начальное обучение вождению проводится: вне населённых пунктов / **на закрытой площадке или автодроме** / на любой дороге → **Ответ 2**.

## Вопросы с картинками (рис.)

Ответы даю с принципом — сами картинки смотри при прорешивании на сайте:

- Сколько полос в данной проезжей части? (рис.) → **Ответ 2 (две)**: полос столько, сколько рядов машин помещается по ширине, а не сколько линий разметки.
- Разрешается ли ехать по центру проезжей части при такой ширине? (рис.) → **Ответ 3 (нет)**: узкая двусторонняя дорога — держись правой стороны.
- Сколько проезжих частей у данной дороги? (рис.) → **Ответ 2 (две)**: проезжие части разделяет разделительная полоса; разметка их не делит.
- Сколько перекрёстков на рисунке? (рис.) → **Ответ 1 (один)**: перекрёсток — одна зона пересечения дорог, сколько бы проезжих частей ни пересекалось.
- Сколько пересечений проезжих частей на рисунке? (рис.) → **Ответ 2 (два)**: дорога с разделительной полосой даёт два пересечения на одном перекрёстке.
- Сколько полос движения у данной дороги? (рис.) → **Ответ 2 (четыре)**.
- На каком рисунке у дороги есть разделительная полоса? (рис.) → **Ответ 2 (на обоих)**: и конструктивная (газон/отбойник), и выделенная разметкой — разделительные.
- На каком рисунке изображён перекрёсток? (рис.) → **Ответ 1 (только на левом)**: выезд с прилегающей территории (справа) — не перекрёсток.
- Пересечение скольких проезжих частей есть на перекрёстке? (рис.) → **Ответ 2 (двух)**.
